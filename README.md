# Reloj digital SH-E-879

Página estática completa, en español y sin dependencias. Funciona sin conexión a Internet.

## Abrir
Descomprime el ZIP y abre index.html en Chrome, Safari o Firefox. También puedes usar Live Server en VS Code.

## Publicar en GitHub Pages
Copia index.html, styles.css, script.js, .nojekyll y la carpeta assets a la raíz del repositorio ElectronicaDigital, sustituyendo los archivos anteriores. Conserva la carpeta .git de TU repositorio. No subas la carpeta exterior como un nivel adicional. Mantén la configuración de Pages que ya utilizas.

## Editar
- index.html: textos, 20 fundamentos, componentes y estructura.
- styles.css: diseño adaptable a computadoras y teléfonos.
- script.js: menú, búsqueda, acordeones, ampliación y demostración de segmentos.
- assets: tres fotografías/esquema originales y el informe PDF.

La fotografía final se orienta horizontalmente mediante CSS, sin modificar su archivo original. La demostración de segmentos es educativa y no controla el circuito físico.

El funcionamiento general y la caja terminada fueron confirmados por el autor. No se inventaron valores de precisión, consumo o respaldo. El informe PDF se conserva sin alteraciones y contiene su bibliografía original; esas referencias no fueron verificadas de forma independiente.
